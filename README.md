# Thesis Skills Library

A GitHub-importable collection of the skills currently available under
`R:\tthheessiiss\.agents\skills`.

## Layout

Every importable skill is under `skills/` and keeps its source directory name.
The collection contains 666 skill roots and 1,687 files. Nested `.git`
directories and local repository metadata were intentionally excluded.

Each skill is recognized by its `SKILL.md` file. This repository is intended
for use with a GitHub skill importer that scans `skills/` directories.

## Provenance and licensing

This is a workspace export for the account that owns the source files. Some
skills may originate from third-party projects and retain their own notices or
licenses. Review the relevant skill directory before redistributing it or
changing the repository visibility.
